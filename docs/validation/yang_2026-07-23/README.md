# Yang Song Five-Seedling Validation Record

These sample-level validation records belong to the dataset-specific workflow
associated with Yang Song of the DroughtFighters project, Plant Microbe
Interaction group, Utrecht University.

The directory name, corpus ID `external:yang-ground-truth-feb-2026`, profile
keys, and related filenames retain the historical technical token `yang` for
compatibility and reproducibility. In every case that token refers to Yang Song
and the project affiliation recorded above.

Private source images and hand annotations are not distributed. The tracked
records contain split identifiers, aggregate and sample-level measurements,
model parameters, and evaluation metadata only.
